# 🐾 Sistema de Gerenciamento de Clínica Veterinária

Este projeto consiste no desenvolvimento de um sistema para gestão de uma **Clínica Veterinária**, criado como requisito prático para a disciplina de **Programação Modular**.

O objetivo principal da aplicação é aplicar na prática os conceitos fundamentais do paradigma modular, garantindo um código organizado, de fácil manutenção, reutilizável e com forte separação de responsabilidades.

---

## 🎯 Objetivos e Conceitos Aplicados

- **Modularização**: Divisão do sistema em módulos independentes e coesos (gerenciamento de pets, tutores, consultas e serviços).
- **Encapsulamento**: Abstração dos dados e funções através da criação de Interfaces (`.h`) e Implementações (`.c`/`.cpp`).
- **Reutilização de Código**: Criação de rotinas genéricas e utilitários compartilhados entre diferentes partes do sistema.
- **Manutenibilidade**: Estrutura clara que facilita a adição de novas funcionalidades e correção de bugs sem impactar todo o sistema.

---

## 🛠️ Funcionalidades Previstas

- 👤 **Cadastro e Gestão de Tutores**: Registro de informações de contato e histórico de clientes.
- 🐶 **Cadastro e Histórico de Pets**: Vinculação de animais aos seus respectivos tutores, com registro de espécie, raça, idade e histórico médico.
- 🩺 **Agendamento de Consultas e Exames**: Controle de horários, veterinários responsáveis e status dos atendimentos.
- 📋 **Relatórios e Consultas**: Listagem de atendimentos, busca por tutores/pets e emissão de resumos.
