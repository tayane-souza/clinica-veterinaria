# 🐾 Sistema de Gerenciamento de Clínica Veterinária

Este projeto consiste no desenvolvimento de um sistema para gestão de uma **Clínica Veterinária**, criado como requisito prático para a disciplina de **Programação Modular** utilizando a linguagem **Python**.

O objetivo principal da aplicação é aplicar os conceitos fundamentais da modularização em Python, organizando o código através de pacotes, módulos (`.py`), funções coesas e forte separação de responsabilidades.

---

## 🎯 Objetivos e Conceitos Aplicados

- **Modularização em Python**: Divisão do código em pacotes e módulos independentes (`tutor.py`, `consulta.py`, etc.).
- **Reutilização e Coesão**: Importação de funções e utilitários compartilhados (`from modulo import ...`) evitando duplicação de código.
- **Abstração e Organização**: Separação clara entre a interface de usuário, e as regras de negócio.
- **Manutenibilidade**: Código limpo e estruturado que facilita a manutenção e adição de novas funcionalidades.

---

## 🛠️ Funcionalidades Previstas

- 👤 **Gestão de Tutores**: Cadastro, edição e busca de informações de contato dos clientes.
- 🐶 **Gestão de Pets**: Vinculação de animais aos seus tutores, com dados de espécie, raça, idade e histórico médico.
- 🩺 **Agendamento de Consultas**: Controle de datas, horários, médicos veterinários e status dos atendimentos.
- 📋 **Relatórios e Listagens**: Exibição de consultas agendadas, histórico por pet e buscas filtradas.
